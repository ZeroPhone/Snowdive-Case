# Snowdive shell files

FreeCAD-designed 3D printable shell source files for Snowdive boards, both standalone and palmtop configuration.

To get STLs for printing, you will need to open this project in FreeCAD, adjust it if necessary, and export different parts manually.
Later on, an exporter script will generate STLs upon each commit.

Files:

* `top_pizero`: shell for Pi Zero-based Snowdive boards
